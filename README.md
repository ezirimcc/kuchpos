# KuchPos

Point of sale and inventory for agricultural products shops.

- [SPEC.md](SPEC.md) — what the app must do.
- [PLAN.md](PLAN.md) — the order it is being built in, with acceptance checks.
- [CLAUDE.md](CLAUDE.md) — project rules, commands and setup notes.

## Running it on this computer

1. Make sure Postgres.app is open and running.
2. Copy `.env.example` to `.env` and fill it in (first time only).
3. Run `npm install` (first time only), then `npm run dev`.
4. Open http://localhost:3000.
